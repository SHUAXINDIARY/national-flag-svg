Rough Emoji Draw （rough-emoji-draw）是一个轻量前端绘图库，把 Unicode 国旗 emoji 绘制成 Rough.js 手写风格 Canvas 图像。常见旗帜使用独立手写模板，其余地区通过 emoji 栅格化与像素采样生成统一风格的 fallback 图像。

本页展示全部 ISO 3166-1 地区旗帜效果，可按地区代码（如 CN）或中文名（如 日本）搜索过滤。

安装： npm install rough-emoji-draw，在项目中 import { RoughEmoji } from "rough-emoji-draw"；或在 HTML 中通过 <script src="https://unpkg.com/rough-emoji-draw/browser"></script> 加载后调用 window.RoughEmoji.draw(canvas, "🇨🇳")。本地开发可引用 dist/rough-emoji.js。详见 中文 README 与 English README。
